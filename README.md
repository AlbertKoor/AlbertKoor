### Olá, sou o Albert

Desenvolvedor back-end em São Paulo, com foco em APIs REST.

Minha stack principal é **Go**, **Node.js** e **SQL Server**. Também trabalho com TypeScript, JavaScript e Python.

Atuo na Clicksign, plataforma de assinatura eletrônica. Antes, desenvolvi APIs e regras de negócio em Node.js na Krypta Solutions.

Meu projeto em destaque é o [cpf-validator-api](https://github.com/AlbertKoor/cpf-validator-api): uma API REST em Go que valida CPF, com a regra isolada em pacote próprio e coberta por testes unitários.

Curso Análise e Desenvolvimento de Sistemas na Universidade Cruzeiro do Sul.
